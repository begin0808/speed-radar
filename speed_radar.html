啟動應用

2

加入主畫面 (推薦)

iOS 使用「分享 -> 加入主畫面」；Android 點擊「菜單 -> 安裝應用」，提升穩定度。

3

開始巡航

點擊「🚀 開始使用」，系統會自動鎖定螢幕衡亮 (Wake Lock)，進入監控狀態。

4

修正與回報

左上角可切換語音開關與「匯出修正檔」。請使用者將取得的 JSON 檔案傳送給開發者 (begin0808@gmail.com)，以便更新主程式資料庫。

預警邏輯 Logic V2.0

1. 動態預警距離 (Dynamic Thresholds) 系統依據道路環境與即時車速自動計算：
• 市區道路：300m 起跳 (最大 500m)，針對低速環境優化。
• 高速/快速公路：500m 起跳 (最大 800m)，確保高速行駛時有充足反應時間。
2. 智慧信任分級 (Confidence Model) 避免誤報的核心技術：
• 高信任 (High)：路名完全匹配，警示最精準。
• 中信任 (Medium)：進入 20 度扇形監控區，且方向角誤差小於 20 度。
• 低信任 (Low)：非行進路徑之相機，系統自動過濾不報警。
3. 漸進式語音階段 (Voice Alert Stages) 二段式提醒確保駕駛注意力：
• 預警階段：播報「前方測速照相，限速 XX」，提供心理準備。
• 緊急階段：距離進入 120m-200m 內，播報「注意，限速 XX」強調危險。

技術架構 Technical Details

空間網格索引 (Spatial Grid Index) 採用 0.02 經緯度單位的網格檢索系統，在大數據量下依然能快速尋找週邊相機。
指向性辨識演算 (Orientation Logic) 結合相機角度 (Direction) 與車輛方位角 (Bearing)，有效解決路口多向誤報問題。
螢幕恆亮機制 (Wake Lock API) 整合現代瀏覽器 Wake Lock 技術，解決手機充電/導航中自動進入休眠的困擾。

PWA 技術與安裝建議 Installation Guide

在「小企鵝超速雷達」中採用 PWA (Progressive Web App) 技術，是為了讓網頁能達到接近手機原生 App 的使用體驗。

什麼是 PWA 技術？

簡單來說，PWA 就是「披著網頁外衣的 App」。它具備以下特點：

  • 可離線執行：透過 Service Worker 技術將資源暫存在手機，確保收訊差時程式不毀損。
  • 無邊框體驗：加入主畫面後自動隱藏網址列，導航畫面更寬廣專業。
  • 背景執行優化：更穩定地申請螢幕恆亮，防止導航途中手機自動進入休眠。

一定要「安裝」嗎？

不一定，但強烈建議安裝。

若不安裝 (瀏覽器開啟) 仍可播報與定位，但網址列佔空間；且切換分頁時 GPS 易被系統自動中斷以節能。
若安裝 (加入主畫面) 像獨立 App 圖示在桌面。執行最穩定，且能維持較高系統權限，確保背景 GPS 運作最流暢。

常見問題 FAQ

Q: 為什麼 GPS 提示「未啟動」或位置不準？
A: 請確認手機的「定位服務」已開啟，並將瀏覽器的地址位置權限設為「允許」。室內可能導致信號微弱，建議到戶外開闊處測試。
Q: 網頁版聲音一定要手動才能開啟嗎？
A: 是的，根據現代瀏覽器安全規範，網頁必須在使用者進行第一次手動互動（如點擊「開始」）後，才能解鎖背景播放權限。
Q: 如何修正錯誤的測速點？
A: 點擊地圖上的相機圖標，使用彈出視窗中的箭頭微調指向，最後點擊左側「匯出修正」並將 JSON 檔提供給開發者 (begin0808@gmail.com) 即可。
Q: 支援背景執行嗎？
A: 作為 PWA 應用，若將其加入主畫面，在螢幕關閉或切換分頁時，只要音訊與 GPS 保持 Active 狀態，仍能提供基礎語音預警。
